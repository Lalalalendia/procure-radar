# Procure Radar — Sterlitamak

Hourly 44-FZ procurement intelligence for Sterlitamak, Republic of Bashkortostan.

The production workflow ingests recent Bashkortostan purchases, resolves city evidence from both customer identity and structured delivery/jurisdiction fields, ranks individual opportunities for first-money tractability, and publishes sourcing-ready dossiers as GitHub Actions artifacts and run summaries.

See `GITHUB_ACTIONS.md` and `DEAL_SCORING.md`.
